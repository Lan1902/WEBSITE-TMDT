# E-commerce Frontend (React + TypeScript + Vite)

1. `npm install`
2. Copy `.env.example` thành `.env`, đặt `VITE_API_URL` trỏ tới API (ví dụ http://localhost:4000/api)
3. `npm run dev` (mặc định http://localhost:5173, khớp với CORS_ORIGIN của back-end)
4. `npm run build` để build bản production (thư mục `dist`)

Trang: / (gợi ý + sản phẩm mới), /products, /products/:id, /cart (kèm đặt hàng), /orders, /login, /register, /admin (sản phẩm, đơn hàng, người dùng).
